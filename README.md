# سیستم مدیریت هوشمند کلینیک

پروژه مدیریت کلینیک چندتخصصی بر اساس [نیازمندی‌های اصلی](prompt.md).

وضعیت فعلی: **مرحله چهارم — هسته فرم‌ساز نسخه‌دار پیاده‌سازی و آزمایش شده است.** ایجاد و طراحی فرم، انتشار تغییرناپذیر، شرط، محاسبه، تکرارشونده، کپی/اشتراک و ثبت نمونه آزمایشی آماده‌اند. محدودیت‌های فایل، متن غنی، تاریخ و AI در راهنمای مرحله چهارم آمده‌اند.

راهنمای اجرای همین دستگاه و ساخت اولین حساب: [مرحله اول](docs/PHASE_1.md).

راهنمای فعال‌کردن مدیر ارشد و مدیریت کاربران، پزشکان و ارتباط کارکنان: [مرحله دوم](docs/PHASE_2.md).

راهنمای ثبت و جستجوی بیمار، شماره مشترک خانواده و محدودیت‌های دسترسی: [مرحله سوم](docs/PHASE_3.md).

راهنمای طراحی فرم، نسخه‌بندی، نمونه‌ها و محدودیت‌ها: [مرحله چهارم](docs/PHASE_4.md). نسخه‌های پروژه در Git محلی روی شاخه `main` ثبت می‌شوند.

برای اجرا، ابتدا `scripts\mysql-start.cmd` (اگر MySQL اجرا نیست) و در ترمینال دیگر `scripts\serve.cmd` را اجرا کنید. برنامه محلی در `http://127.0.0.1:8000/login` در دسترس است. نسخه‌های وابستگی در lockfileها ثبت شده‌اند.
